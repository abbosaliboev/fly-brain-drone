# Python 3.11. Install torch first with the CUDA index for this machine:
#   pip install torch --index-url https://download.pytorch.org/whl/cu124
# then:
#   pip install -r requirements.txt
#
# Note: if pip hangs retrying a host called pypi.ngc.nvidia.com, this
# machine has a stale global pip.ini (from an older NVIDIA PyIndex install)
# pointing at a dead extra-index-url. Work around per-install with:
#   $env:PIP_CONFIG_FILE = "NUL"   (PowerShell)
# rather than editing the shared user pip.ini, since other projects may rely on it.
#
# IMPORTANT: never pass --extra-index-url alongside --index-url for torch —
# pip will pick the highest-versioned match across BOTH indexes, which can
# silently select the CPU-only build from public PyPI instead of the CUDA
# build. Verify after install: `python -c "import torch; print(torch.__version__)"`
# must show a "+cu124" (or similar) suffix, not a bare version number.
